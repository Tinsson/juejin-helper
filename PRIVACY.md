# Privacy Policy

掘友小助手 is a Chrome extension for viewing Juejin creator data, article data, notification counts, and related Juejin content.

## Data Access

The extension accesses Juejin account data only when the user is signed in to Juejin in Chrome. It requests data from Juejin APIs to display:

- Basic user profile information
- Notification counts
- Check-in status
- Creator power and article analytics
- User-related Juejin content search results

## Local Storage

The extension stores basic Juejin user profile information in the extension page's local storage to reduce repeated requests. This data stays on the user's device.

## Data Sharing

The extension does not sell, transfer, or share user data with third parties. It does not send user data to any service other than Juejin APIs needed for the extension's visible features.

## Browsing Activity

The extension does not read, collect, store, or transmit Chrome browsing history.

## Network Requests

The extension does not modify browser request headers or network traffic. Network access is limited to Juejin domains required by the visible extension features.

## Contact

For questions about this policy, contact the maintainer listed in the extension manifest.
